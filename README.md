Это небольшой проект под названием todo. Он работает  на основе пяти эндпоинтов и позволяет: смотреть все задачи, смотреть задачу по айди, добавлять задачу, обновлять задачу по айди и соответсвенно удалять. Дабы запустить проект надо иметь у себя интерпретатор Пайтона, а также установить зависимости fastapi, uvicorn.
